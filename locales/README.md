# Переводы Sequoia

Каталоги используют формат Maploom с идентификаторами строк вида `settings.title`.
Сами файлы независимы от Maploom: поле `format` должно быть `sequoia/locale`.

## Добавление языка

1. Скопируйте `en.json` в новый файл, например `de.json`.
2. Измените `id` на `de`, а `name` — на `Deutsch`. Название показывается в списке языков.
3. Переведите значения в `strings`, сохраняя ключи и параметры в фигурных скобках.
4. Положите файл в папку `locales` рядом с исполняемым файлом или в `locales` внутри папки данных Sequoia.
5. Полностью перезапустите приложение. Выберите язык в **Настройки → Общие → Язык интерфейса** и нажмите **Сохранить**.

Регистрация языка в Rust или скриптах сборки не требуется. В разработке также
сканируется папка `locales` проекта. Сборка автоматически встраивает все JSON из
этой папки и копирует папку в дистрибутив. Внешние файлы переопределяют встроенные;
каталоги из папки данных имеют последний приоритет. При совпадении `id` внутри
одной папки используется последний файл в порядке имён.

```json
{
  "format": "sequoia/locale",
  "version": 1,
  "id": "de",
  "name": "Deutsch",
  "strings": {
    "settings.title": "Einstellungen",
    "settings.save": "Speichern"
  }
}
```

UTF-8 с BOM или без него; размер до 1 МиБ. `id` содержит 1–32 латинские буквы,
цифры, дефисы или подчёркивания. `name` не может быть пустым. Для полного перевода
используйте весь английский каталог, а не только пример выше. Повреждённый каталог
пропускается; сообщение о нём появляется в категории «Общие».

Отсутствующие или пустые переводы дополняются английскими строками. Неизвестный
ключ показывается как есть. Если сохранённый язык недоступен, используется русский.
Системные диалоги, ошибки ОС и диагностические сообщения внешних программ могут
использовать собственный язык. Тестовые названия файлов и композиций не переводятся.

Параметры `{arg0}`, `{arg1}`, `{count}`, `{name}`, `{e}` заменяются приложением.
Их можно переставлять вместе с окружающим текстом, но нельзя переименовывать.
Для переноса строки используйте `\n`. Формат чисел и времени задаётся приложением.

Проверка каталогов и механизма загрузки: `cargo test --test i18n`.
